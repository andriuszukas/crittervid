# GardenCamera Copilot Chat Summary

## Project Overview
GardenCamera is a Python-based pipeline for processing wildlife camera video files. It automates the conversion of proprietary `.media` files to `.mp4`, merges them into longer clips, and validates the output. The workflow is designed for efficiency, robustness, and extensibility, supporting GPU acceleration and parallel processing.

## Key Features
- **Batch Conversion**: Converts `.media` files to `.mp4` using FFmpeg, with support for GPU acceleration (CUDA, QSV, VAAPI, AMF).
- **Merging**: Groups and merges `.mp4` segments into 12-hour clips per camera, preserving timestamps and camera IDs in filenames.
- **Validation**: Checks output files for correct naming and playability, using parallel processing for speed.
- **Automation**: Scripts recursively process all folders, handle new files, and generate summary reports.
- **Error Handling**: Logs failed conversions/merges and skips corrupted files, reporting issues in summary logs.
- **Extensibility**: Designed to support new camera models and file formats easily.

## Main Scripts
- `convert_media.py`: Converts `.media` files to `.mp4` with parallel and GPU support.
- `merge_videos.py`: Merges `.mp4` files into longer clips, using robust regex grouping.
- `validate_output.py`: Validates output files in parallel, ensuring correct naming and playability.
- `process_all.py`: Orchestrates the full workflow, forwarding parameters and supporting dry-run mode.

## Technical Highlights
- **Regex Grouping**: Updated regex in `merge_videos.py` to match filenames with three segments (timestamp, camera ID, segment index).
- **Picklable Validation**: Refactored validation functions to be top-level for compatibility with `ProcessPoolExecutor`.
- **Parallelism**: Uses ThreadPoolExecutor/ProcessPoolExecutor for conversion and validation.
- **Graceful Interruption**: Handles KeyboardInterrupt for safe stopping.
- **Summary Logging**: Generates summary reports for conversion, merging, and validation steps.

## Limitations & Notes
- **FFmpeg Validation**: Hardware acceleration (`-hwaccel`) is used for decoding, but most validation work is CPU-bound.
- **Merging**: By default, merging uses `-c copy` (no re-encoding, CPU only). GPU can be used if re-encoding is required.
- **Copilot Chat Sessions**: Chat history is not synced between devices. To continue on another PC, push your code to a remote repo and provide context manually in a new chat session.
